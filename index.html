How it works

  1. Get a game file from a disc you own. .chd or .pbp single files work best.
  2. Drop it above. The emulator loads in your browser.
  3. Save states are stored in your browser, so keep using the same one.

Have a .cue + .bin pair? Convert it to a single .chd with the free chdman tool first.
